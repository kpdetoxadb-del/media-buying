The numbers are placeholders you replace with your account's top-performer medians after 30 days of data. Calibrate monthly (see Monthly Step 6).

Compare this week's top 10 vs last week's

Action

4
Kill / keep on test ads — Pacing Gate first
Testing Campaign · Check Day-of-Week Pacing Tracker before any kill

Before touching any ad — check today's day classification in the Day-of-Week Pacing Multiplier Tracker.

Action
Kills happen NOW on Baseline/Surge days. On Pullback Days: reduce budget only. Do not touch ads. Graduations: any test ad hitting target at 2–3× CPA spend → classify winner type → move to scaling.
5
Drop one note per shift noticed
Motion → Click Ad → Notes

Future-you needs this. Three weeks from now you will not remember why you killed ad #417. One sentence. No more.

Action
"Killed – low CVR at $1.8k spend."
"Graduating – ROAS 2.4 at $900 spend, top 10 pattern match."
"False Winner – collapsed at 2× budget."
⚡ Day-of-Week Pacing Gate · Run before every kill/keep decision
↑ SURGE DAY (+20% vs avg)
Apply normal kill gate. Also flag CBO budget +20% for tomorrow. Performance above average — let it run.
→ BASELINE DAY (±20% of avg)
Apply normal kill gate. Any test ad that spent 2–3× target CPA without converting → kill. Any hitting target at spend threshold → classify and graduate.
↓ PULLBACK DAY (–20% vs avg)
Do NOT kill any ad. Low performance is the auction, not the creative. Reduce CBO budget –20% for tomorrow. Mark all test ads WAIT. Come back tomorrow.
Daily Gate: Did something shift dramatically? → Flag for Weekly. No shift? → Close the laptop. Done.
📅Weekly
30–45 minutes · Monday morning
You shift from observer to diagnostician. Where real diagnosis happens.
1
Filter for statistical significance
Motion → Add Filter: Spend ≥ 2–3× Target CPA

Only ads above this filter are statistically significant. Everything below is noise — ignore it. This separates what's actually working from what just looks like it is.

Action
Study only ads above the filter. Everything below: do not act on it yet. Let it spend to threshold first.
2
Diagnose under-performers + log ad blocks
See diagnostic tree below · Soft metrics first → hard metrics second · Pull data from Motion before starting

Open Motion and pull each ad's metric data. Reference: CF _ Ad Analysis Guide for metric definitions, calculations, and what each number means before acting on it.

For each ad above spend threshold that's missing target, diagnose in this order — never jump steps:

  • Start with ROAS/CPA — is the ad profitable at all?
  • Then Thumbstop rate — is the visual stopping the scroll?
  • Then Hook rate — are people staying past 3 seconds?
  • Then Hold rate — is the body holding attention?
  • Then CTR — are people clicking? Low CTR with strong hook = CTA or offer frame problem.
  • Then post-click CVR — if CTR is fine but CPA is high, the issue is on-page, not creative.

After every diagnosed ad — winners AND losers — break it down by ad blocks and log validated blocks (or blocks with high retention) into the Building Blocks Repository. Any failure pattern that must not repeat gets logged in the Strategic Learning Note column in Sprint Planning - Concept Testing Tracker.

Action
Every ad gets a diagnosis. Every winner and high-retention block → Building Blocks Repository. Every failure → update Sprint Planning - Concept Testing Tracker - Strategic Learning Note column (hypothesis, failure diagnosis, one-sentence rule). Map diagnosis to an iteration lever in the SOP.
3
Retention Graph Surgery on Fix candidates
Motion → Individual Ad View → Retention Graph

For every ad diagnosed as needing a Fix iteration, run Retention Graph Surgery to find exactly where the drop happens:

  • 0–3s drop: Hook problem → Ladder 1: Hook Refresh
  • 3s–25% drop: Lead problem → Ladder 2: Script Tightening (opening)
  • 25–50% drop: Body problem → Ladder 2: Script Tightening (middle)
  • 50–75% drop: Offer frame problem → Ladder 2: Script Tightening (offer)
  • 95%+ drop: CTA problem → rewrite last 3–7 seconds
Action
Drop point tells you which Iteration Ladder level to pull. Write the Fix hypothesis: "If we execute [CHANGE] on [WINNER], then [METRIC] will improve because [RATIONALE]." One change. Rule of One.
4
Hook rate check — Ugly Duckling scan
Motion → Hook Iteration Report

Analyze Thumbstop rate vs ROAS across all active ads. Look for the Ugly Duckling: weak hook/hold rate BUT strong ROAS.

Ugly Duckling = the message is correct, the execution needs a reshoot. Do NOT change the angle. Iterate the execution only.

Action
Ugly Duckling found → brief a Hook Refresh (Ladder 1) or new caster (Ladder 3). Keep the script and angle identical. Note it as "execution problem, not message problem" in Turning Dirt Into Gold - Account Intelligence column (Master file).
5
Site experience check
Motion → GA · Site Metrics

Bounce Rate, Time on Site, funnel drop-off. If the ad is clean but CVR is poor — it may be the site, not the creative.

  • Drop-off at PDP + ATC → product page issue
  • Drop-off at ATC + Checkout → checkout friction
Action
Flag post-click issues to dev. Do not brief more creative to fix a site problem. Log in diagnosis: "post-click issue, not creative."
6
Classify winners + fill Execution Intelligence + update Building Blocks
See Winner Classification below

Any ad that cleared the Validation Gate (2–3× Target CPA spend) this week gets classified. Run Pacing Gate check first.

After classification, fill Sprint Planning - Launched tab - 🧠 Execution Intelligence column for all variables: condition, persona, awareness, sophistication, EPIC, angle, execution insights. One sentence on what you did NOT know before.

For kills: log hypothesis, failure diagnosis, do-not-repeat sentence.

Every winner and every block showing high retention — hook type, body structure, CTA format, visual style — gets logged into the Building Blocks Repository. This is the long-run compound asset that makes future briefs faster and your hit rate higher.

Action
Grand Slam → graduate to CBO, begin Iteration Ladder 1–4 immediately.
Low-Profile → keep in ABO at sweet spot, Ladder 1–2 only.
False Winner → archive. Do not relaunch. Salvage validated blocks.

All validated blocks → Building Blocks Repository. All failure patterns → do-not-repeat log.
7
Plan next week's batch — Weekly Creative Meeting
30 min · Align with media buyer · Set the 20/60/20 mix

Review Concept Testing Tracker before ideation. Set the week's mix based on account goals and 5-Phase position:

  • 60% More/Fix iterations — winners multiplied or bottlenecks repaired
  • 20% Net New / Adapt / Expand (shared slot, split per weekly meeting) -- Net New: fresh concept from scratch; Adapt: production ascension graduation; Expand: new concept on validated Grand Slam foundation

Which funnel to push is decided HERE, not by a rigid sequence. Media buyer input drives this decision based on account goals.

Action
Document every planned ad with its hypothesis. Fill the Weekly Creative Direction Tracker. Hand briefs to production. Confirm naming convention for every ad before launch.
🏆 Winner Classification · Run after Validation Gate clears (2–3× Target CPA spend · Pacing Gate checked) · All validated blocks → Building Blocks Repository
❌ False Winner
Looked great 24–72 hrs. Collapsed on budget increase. Do NOT relaunch. Salvage validated blocks (strong hook rate? extract it). Archive the ad. Do not invest iteration budget here.
○ Low-Profile Winner
Profitable at $50–200/day in ABO. Chokes in CBO. Keep at its sweet spot. Surgical iterations: Ladder 1–2 only. Fix one choke point at a time. Stack 10+ for stable base spend.
★ Grand Slam
Scales aggressively. Holds KPI as budget increases. Graduate to CBO. Iterate all 4 Ladder levels. Scale with +20% Rule. Protect the original — don't "improve" it until it dies.
Diagnostic Decision Tree · Weekly Step 2 · Run on every under-performer above spend threshold
Gate 1 — Is the ad hitting ROAS / CPA target?
↓ NO, UNDER TARGET — has it spent 2–3× target CPA? If not, do nothing yet.
Gate 2 — Thumbstop rate (3-second view rate)?
↓ Below 20% = Hook problem → Ladder 1: Hook Refresh (visual, text overlay, or audio — Rule of One)
Gate 3 — Hook rate (5s views ÷ 3s views)?
↓ Below 30% = Hook is stopping scroll but not holding — qualify audience in first 3s or rework opening line
Gate 4 — Hold rate (15s views ÷ 3s views)?
↓ Below 20% = Body problem → Ladder 2: Script Tightening. Run Retention Graph Surgery to find exact drop point.
Gate 5 — CTR (link clicks ÷ impressions)?
⬆ Low CTR (<0.8%) → CTA / Offer Frame Problem
Hook and body are holding people but they're not clicking. The offer, CTA, or relevance bridge is weak.

Low CTR + high hold rate → Angle is resonating but offer is unclear. Tighten CTA, add urgency/scarcity, clarify the offer frame. Ladder 2: Script Tightening on the offer section.

Low CTR + low hold rate → Angle is not resonating. Pivot to a new angle or condition.
✓ CTR OK but CPA high → Post-Click Problem
The ad is qualified and clicking, but the page is not converting.

High CTR + high CPA → Ad and page are not congruent. Adjust messaging in ad to bridge gap with page headline, or consider a dedicated lander for this condition (Production Investment Ascension Stage 4).

High CTR + low hook rate → Hook is qualifying well (fewer clicks but buyers). Keep angle, test new visual to open the audience wider.
The Rule: ROAS/CPA gate first → Thumbstop → Hook rate → Hold rate → CTR → post-click CVR. Always in that order. Never jump steps.

60–90 minutes · 1st of the month

1
Creative fatigue check — CPM vs ROAS
Motion → Creative Fatigue Report · Line View · Last 4–6 weeks

CPM up, ROAS down = market problem (seasonality, auction pressure). Not creative fatigue. Shift budget or wait it out.

Both trending down = creative fatigue confirmed. Trigger iteration refresh. If iterations fail → move to Adapt or Net New.

Action
Diagnose market vs creative before briefing anything new. Wrong diagnosis = wasted budget. Market problem → don't brief more creative. Creative fatigue → trigger Iteration Ladder refresh.
2
Creator / actor comparison report
Motion → Comparative Analysis · Creator Comparison

Sort creators by total revenue generated. Click into the top one — study their pattern. Which EPIC category? Which hook style? Which execution format?

Action
Book 2–3+ more content from top creator next month. Add their name and specific style notes to next sprint brief. Feed pattern into Building Blocks reference library.
3
Launch analysis — 4 tabs
Motion → Launch Analysis Report

Set winning benchmark (ROAS + spend). Review all four tabs:

  • Launched — created but not yet live. Flag anything stalled.
  • Scaled — ads that are spending meaningful budget.
  • Winners — dissect why each won. EPIC tag, angle type, hook type, execution style.
  • Opportunities — underperforming, worth fixing via Retention Graph Surgery.
Action
Share with media buying team. Notes on each tab. For every Winner: log in Sprint Planning - Launched tab - 🧠 Execution Intelligence column. These patterns feed next month's briefs.
4
Pull landing page language into ads
Motion → Group by Landing Page

If one landing page dominates the winners, pull its strongest headline into the ad as a text overlay. Message-to-market match reduces friction — if the ad and the landing page speak the same language, CVR improves.

Action
Test winning LP headline as ad text overlay (one variable — Rule of One). Feed LP language into the Quote Bank and into the angle brief for next batch.
5
Confirm next month's 20/60/20 mix
The data tells you. The weekly analysis already showed what's working.

The performance data from the past month determines the mix. The weekly analysis already surfaced what the account needs. Confirm and commit: More (20%) + Fix (60%) + [Net New / Adapt / Expand] (20% shared, split per weekly meeting).

Action
Confirm mix with media buyer. Brief production accordingly.
6
Recalibrate your benchmark numbers
Your Own Data · Update Personal Benchmark Card

Filter spend ≥ 2–3× Target CPA → ROAS ≥ target. The median of those ads = your new benchmarks. Replace the starting-reference numbers in this workflow with your real data.

Update: CTR floor · CVR floor · Hold rate target · CPC acceptable range · Motion spend filter.

Action
Update your benchmark card. The numbers in this workflow are placeholders — your account's real medians are the law. Do this every month. Don't skip it.
7
Day-of-Week Pacing Audit
Meta Ads Manager → Breakdown → Day of Week · Last 30–60 days · Open Pacing Tracker

Export the last 30–60 days grouped strictly by day of week. Paste into the Day-of-Week Pacing Multiplier Tracker (columns B & C). The sheet auto-calculates variance vs your Northstar average and outputs a budget action for every day.

  • Surge Day (≥+20% vs avg): Increase CBO scaling budget +20% the night before.
  • Pullback Day (≥–20% vs avg): Decrease CBO budget –20% the night before. Do NOT kill or brief a Fix iteration — this is the auction, not the creative.
  • Baseline (±20%): Hold budget flat.
Action
Set CBO daily budget rules for the upcoming month the night before each day. Drop one note: "June Pacing — Surge: Mon/Thu · Pullback: Sun · Baseline: rest." If an ad drops on a Pullback Day — ride it out. Reduce budget. Do not kill.
↓ Start of every quarter
✦Quarterly
~2 hours · start of each quarter
You're not diagnosing ads. You're asking if you're playing the right game.
1
Re-classify the account phase
5-Phase Scaling Roadmap · Has the account grown?

Check where the account sits in the 5-Phase Roadmap. Has revenue grown into a new phase? Each phase changes what you're allowed to focus on:

  • $0–10K/mo: Find the Trojan Horse. Everything is a test.
  • $10K–100K: Protect and multiply the Trojan Horse. 80% iteration.
  • $100K–500K: Systematically open new angles via EPIC.
  • $500K–1.5M: Open new audiences with entirely new messaging.
  • >$1.5M: TAM expansion — new channels, new product lines.

Remember: every phase is additive. You keep feeding the lower one when you go up.

Action
Re-allocate production hours based on new phase. Adjust weekly 20/60/20 mix accordingly. Update condition specificity target (General at low spend → Hyper-Specific at high spend).
2
Full performance audit — patterns across time
Motion · Quarter view · EPIC audit + Building Blocks review

Pull performance broken down by creative element — not overall results. Look at:

  • Hook rate + Hold rate as diagnostic patterns across the quarter.
  • Which EPIC categories are over-represented in your winners? Which are absent?
  • Which Building Blocks (hook types, body types, CTA types) are appearing in top performers?
  • Which persona + condition combinations validated? Which failed repeatedly?
Action
Translate audit findings into creative strategy direction for the quarter. Update Building Blocks reference library with new validated blocks. Refresh EPIC Audit Tally section in Master file - In-Depth Audit tab - PART 4. Feed into Q's Angle Generation pre-read.
3
Reset quarterly goals — ONE Northstar metric
Brand · Account-level planning

Set the quarter's creative targets: concepts delivered · win rate · Northstar metric confirmation.

ONE Northstar metric only. Never two. Never negotiate. ROAS for D2C ecom. CPA for apps/subs/leads. If someone gives you two — push back: "What's the ONE most important metric?"

Action
Document the ONE Northstar. Set production targets. Confirm 5-Phase classification. Brief the quarter's strategic focus to media buyer. Align on which conditions are the priority battlefields.

The 6 Rules That Sit Above All Cadences

#1
Rule of One
Change ONE variable when iterating (More/Fix). Only break this for Net New/Adapt hook testing (5 diverse hooks).
#2
Spend Before Judgment
No kill/keep decision below 2–3× Target CPA spend. Below that threshold is noise, not signal.
#3
CPC → CVR, Always
Soft metrics first (Thumbstop, Hold). Then CPC gate. Then CTR or CVR split. Never reverse the order.
#4
Market vs. Creative
CPM up + ROAS down = market problem. Both down = creative fatigue. Diagnose before briefing anything new.
#5
One Northstar Metric
Never two. ROAS for D2C ecom. CPA for apps/subs/leads. If someone gives you two — push back.
